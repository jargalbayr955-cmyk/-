# Ачилт Жолооч — Android preview

Android 8+ суулгадаг жолоочийн апп. Одоогийн утас + PIN нэвтрэлт, MapLibre газрын зураг,
үнийн санал, төлбөрийн хуудсуудыг HTTPS WebView дотор ашиглана. Хэрэглэгчийн сайт хэвээр.

## Хэрэглэх

1. APK суулгаад админы бүртгэсэн утас + PIN-ээр нэвтэрнэ.
2. Профайлд машины төрлөө сонгоно.
3. Дээд талын **Ажиллаж эхлэх** дарж тайлбарыг зөвшөөрнө.
4. Нарийвчилсан байршил, мэдэгдлийг зөвшөөрч GPS-ээ асаана.
5. **GPS ажиллаж байна** гэсэн төлөв гарсны дараа дэлгэцээ түгжиж болно.
6. **Амарч эхлэх**, эсвэл мэдэгдлийн мөрний адил товч байршлыг зогсооно.
7. **⋮ → Гарах** байршлыг зогсоож, төхөөрөмжийн нэвтрэлтийг цэвэрлэнэ.

## Ажиллах зарчим, хязгаар

- `location` төрлийн foreground service зөвхөн жолоочийн үйлдлээр эхэлнэ.
  Ажиллах турш Android мэдэгдэл харагдана. `ACCESS_BACKGROUND_LOCATION` шаардахгүй:
  үйлчилгээг дэлгэц дээрх Activity эхлүүлж, цааш ажиллуулна.
- Ойролцоогоор 20 секунд + хүсэлтийн хугацааны зайтай серверээс захиалга шалгаж,
  шинэ урилга болон сонгогдсон саналд Android мэдэгдэл гаргана. Энэ preview нь
  Firebase/FCM push ашиглахгүй. Сүлжээ, Doze, батарейн хязгаарлалтаас хоцорч болно.
- GPS-ийн нас 60 секундээс их, нарийвчлал 150 метрээс муу бол илгээхгүй.
  GPS олдохгүй 2 минут болоход үйлчилгээг зогсооно. Хуучин байршлыг шинэ мэт
  тасралтгүй явуулахгүй. Серверийн шинэ байршлын 2 минутын шалгуур хэвээр.
- Үнийн санал сонгогдсон идэвхтэй ажлын үед байршил үргэлжилнэ. Ажил дуусаж
  төлбөр хүлээгдэхэд зогсоно. Төлбөр батлагдсаны дараа жолооч ажлаа дахин эхлүүлнэ.
- Байршлын heartbeat жолоочийг дур мэдэн дахин онлайн болгохгүй.
- Нэвтрэлт хүчингүй болох, өөрчлөгдөх, GPS/мэдэгдлийн зөвшөөрөл хаахад зогсоно.
- Амрах үед GPS listener сална. Сүлжээ тасарвал серверийн offline төлөв
  батлагдахгүй байж болно; байршил хуучрахад шинэ захиалгын сонголтоос хасагдана.
- Утсаа restart хийх, Force stop хийх, Android үйлчилгээг устгах үед автоматаар
  дахин эхлэхгүй. Аппаа нээж **Ажиллаж эхлэх** дарна.
- PIN-ийг native код хадгалахгүй. HTTPS, WebView-ийн HttpOnly driver cookie ашиглана.
  Админ/хэрэглэгчийн cookie native хүсэлтэд очихгүй. Сертификатын алдааг тойрохгүй.
  JavaScript-to-native bridge байхгүй, backup унтраалттай, үйлчилгээ гаднаас нээгдэхгүй.
- iPhone хувилбар энэ Android төсөлд ороогүй. Native iOS хэрэгжүүлэлт,
  Apple signing/TestFlight болон бодит төхөөрөмжийн шалгалт тусдаа шаардлагатай.

## Build

Android Studio, JDK 17, Android SDK Platform 36, Build Tools 36.0.0 шаардлагатай.
`mobile/android` фолдерыг Android Studio-оор нээнэ. SDK лицензийг уншиж зөвшөөрнө.

```sh
cd mobile/android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows: `gradlew.bat testDebugUnitTest lintDebug assembleDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.
Preview package `mn.achilt.driver.preview` — production release-ээс тусдаа.
Release signing key репод хадгалахгүй. Play Store-д нийтэлсэн production апп биш.

## Утсан дээр баталгаажуулах

Автомат build/unit/lint нь доорх бодит төхөөрөмжийн шалгалтыг орлохгүй.

| Нөхцөл | Хүлээгдэх үр дүн |
| --- | --- |
| Нэвтрээд аппыг дахин нээх | PIN дахин шаардахгүй, GPS өөрөө асахгүй |
| Нарийвчилсан GPS зөвшөөрөхгүй | Ажил эхлэхгүй, ойлгомжтой заавар |
| GPS, мэдэгдэл зөвшөөрөөд ажиллах | Серверийн байршил шинэчлэгдэж, мэдэгдлийн мөр харагдана |
| Дэлгэц түгжээд 10 минут алхах/зорчих | Байршил үргэлж шинэ; батарей, өгөгдлийн зарцуулалт хэмжих |
| Өөр апп ашиглах | GPS үргэлжилж, захиалгад мэдэгдэл ирэх |
| Шинэ урилга давтан шалгах | Ижил урилгад давхар мэдэгдэл өгөхгүй |
| Санал сонгогдох | Сонгогдсон мэдэгдэл, зөв захиалга нээгдэх |
| Интернэт таслаад сэргээх | Алдааны төлөв; холбогдоход шинэ GPS явуулах |
| GPS унтраах/зөвшөөрөл цуцлах | Ажил зогсох; GPS үргэлжлүүлэн илгээхгүй |
| Амарч эхлэх/мэдэгдлийн stop | GPS listener салж, сервер offline болох |
| Гарах/өөр жолоочоор нэвтрэх | Хуучин жолоочийн ажил, байршил холилдохгүй |
| Restart/Force stop/батарей хэмнэх | Хязгаарлалт ил тод, ажил дахин эхлүүлэх шаардлагатай |

Android-ийн үйлдвэрлэгч бүрийн батарейн бодлого ялгаатай. Бодит утсан дээр
дэлгэц түгжээтэй шалгалт хийгдэх хүртэл production-ready гэж тооцохгүй.
