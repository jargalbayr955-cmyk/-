# Ачилт V5.5 — уялдаа холбооны шалгалт, 2026-09-22

## Дүгнэлт

Кодын доорх алдааг засаж, Supabase migration-ийг хэрэгжүүлсэн. Автомат тестүүд болон бодит өгөгдлийн сан дахь буцаах горимтой туршилтууд нь үндсэн урсгалуудыг баталсан. Банк/MacroDroid-ын бодит холболт, хуучин бүртгэлийн зөрүү, хоёр утасны бодит туршилт үлдсэн учраас “ямар ч асуудалгүй” гэж дүгнээгүй.

## Зассан асуудлууд

## Баталгаажуулсан хүрээ

- PIN-ээр бүртгүүлэх/нэвтрэх, cookie хадгалах, өөр төхөөрөмжийн нэвтрэлт, хугацаа сунгах, гарах, идэвхгүй хэрэглэгчийг хориглох.
- GPS-ийн хоцорсон хариу гараар сонгосон цэгийг дарахгүй; жолоочийн идэвхтэй үеийн GPS, байршил хуучирсан үеийн хязгаарлалт.
- Ойрын 8 жолооч, машины төрөл, 10 минутын саналын цонх; жолооч дараа онлайн болоход хоосон хайлт сэргэх.
- Санал сонгох, өөр хүний захиалгыг харах/сонгохыг хориглох, утасны дугаарыг сонголтын дараа хуваалцах.
- Давхар сонголт, давхар дуусгалт, давхар SMS төлбөр нэмж үүсгэхгүй.
- 112,820 ₮-ийн 5% болох 5,641 ₮ → 5,500 ₮; 5,750 ₮ → 6,000 ₮. Дүн ба 6 оронтой код хоёулаа яг тохирох ёстой.
- Төлбөр төлөгдсөн ч өөр өртэй, идэвхтэй ажилтай, админ хаасан жолоочийг зөвшөөрөлгүй онлайн болгохгүй.
- Админ төлбөрийн хайлт бүх жагсаалтад ажиллах; утас, улсын дугаар, кирилл, зай/зураас, хуудаслалт.
- Видео: зөвхөн сонгогдсон хос, нэг төхөөрөмжийн эзэмшил, зэрэг залгах, таслах, камераа хаах, зөвшөөрөлгүй/дууссан захиалгыг хориглох. Энэ нь бодит хоёр гар утасны дүрс/дууны туршилтыг орлохгүй.

Шалгалт: JavaScript/TypeScript-ийн 219 автомат тест, `eslint --quiet`, production build. Supabase дээр `auth`, `dispatch`, `payment`, `commission-payment`, `admin-payment-search`, `video`, `retry`, `audit-integrity` гэсэн 8 SQL багц ажилласан. Бүх SQL туршилтын өгөгдөл буцаагдсан; бодит PIN болон төлбөр өөрчлөөгүй.

## Үлдсэн ажил ба хязгаар

1. **Банк, MacroDroid:** өгөгдлийн санд банкны нэр, бүрэн данс, SMS sender-ийн тохиргоо байхгүй. Админ → Тохиргоо хэсэгт оруулж, жинхэнэ орлогын SMS-ээр шалгах шаардлагатай. Parser/RPC-ийн тест давсан нь утсан дээрх MacroDroid ажиллаж байгааг батлахгүй.
2. **Хуучин өгөгдөл:** жолоочгүй боловч confirmed төлөвтэй 27 захиалга байна. 3 захиалгын төлбөрийн мөр давхардсан; тэдгээрийн 2-т unpaid мөр байна. Баримтгүйгээр хаах, устгах, төлөгдсөнд тооцохгүй. Админ санхүүгийн баримттай тулгаж шийдвэрлэх хэрэгтэй.
3. **Бодит төхөөрөмж:** зөвшөөрөлтэй хэрэглэгч/жолоочийн хоёр утсаар видео, push, дэлгэц түгжих/апп хаах үеийн ажиллагааг шалгах үлдсэн. Web browser хаалттай үед GPS тасралтгүй илгээх баталгаа байхгүй. Native Android GPS service тусдаа урсгалтай бөгөөд энэ удаа APK-г дахин build хийгээгүй.
4. **Газрын зураг:** MapLibre 6 WebGL2 шаарддаг. Хуучин WebGL1-only төхөөрөмж шинэ browser хэрэгтэй. Газрын зургийн worker-ийн build/import graph шалгагдсан; хэрэглэгчийн бодит төхөөрөмжийн GPU дээр харагдах байдал тусдаа шалгалт шаарддаг.
5. **Нэвтрэлттэй browser E2E:** автомат тестүүд HTTP/DB/компонентын холбоосыг хамарсан. Энэ шалгалтын browser дээр хэрэглэгч/жолооч/админаар нэвтэрсэн session байгаагүй; бодит дансаар захиалга, төлбөр хийсэн гэж тайлагнаагүй.
6. **Supabase-ийн платформын зөвлөмж:** PostGIS `public` schema-д, `spatial_ref_sys` RLS-гүй, `st_estimatedextent`-ийн 3 overload нь anon/authenticated-д нээлттэй байна. Эдгээр extension object-ийг `supabase_admin` эзэмшдэг; холбогдсон `postgres` эрхэд grant өөрчлөх эрх байхгүйг шалгасан. Аппын users/drivers/orders/offers/payment_codes/settings хүснэгтүүд RLS-тэй, anon/authenticated шууд SELECT эрхгүй. Supabase Auth-ийн leaked-password тохиргооны анхааруулга мөн үлдсэн; энэ аппын өөрийн PIN auth-д шууд үйлчлэхгүй.
